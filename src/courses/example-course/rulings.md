# Rulings — example-course

Judgment calls made by Ki without asking, each with the default
taken and the cost if it is wrong. New rulings append below, numbered on.

    R<n>: <choice> — default: <what was done>, cost if wrong: <downside>

R1: quiz file naming — default: week-prefixed (`week04-quiz.md`), cost if
wrong: renumbering files later if the schedule shifts.

R2: statistics examples use everyday data — default: food prices and
weather rather than abstract or disciplinary data, cost if wrong: less
engaging for some cohorts; swap on the educator's note.
